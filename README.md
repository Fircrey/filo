# Filo

SaaS para profesionales de la belleza en Latinoamérica, en web y móvil. Un producto de [Magnor](https://magnor.tech).

**Caso de estudio** · Producto Magnor · Piloto remunerado · Código privado

## El problema

Los profesionales de la belleza en Latinoamérica necesitan una herramienta pensada para su trabajo, disponible tanto en el ordenador como en el móvil.

## La solución

Una plataforma SaaS con versión web y app móvil, construida sobre una API propia de 73 endpoints y un modelo de datos de 29 tablas.

## Mi papel

Participé en todas las capas del proyecto, de la idea a producción:

- **Desarrollo:** frontend, backend y base de datos, además de integraciones con MCP.
- **Puesta en producción:** configuración de dominios y publicación de versiones.
- **Calidad y mantenimiento:** revisión y corrección de errores y parches.
- **Seguimiento:** atento al estado del proyecto de principio a fin, proponiendo e implementando mejoras.

## Resultados

- **En pilotos remunerados.**
- **29 tablas** y **73 endpoints**.
- **176 pruebas automatizadas.**

## Stack

Next.js · Expo · Drizzle · PostgreSQL
